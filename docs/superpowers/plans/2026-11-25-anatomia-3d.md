# Anatomia 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Seterra-style RO/EN anatomy click quiz (bones, muscles, nerves) on a rotatable 3D BodyParts3D body, with a dithered title skeleton and Romanian documentation.

**Architecture:** A static site of plain ES modules with no build step. Game logic (`quiz.js`, `i18n.js`, `storage.js`) is DOM-free and unit-tested with `node --test`. Rendering (`scene.js`, `dither.js`) and screens (`main.js`, `results.js`) are verified in the browser. Models come out of a one-off Node pipeline in `tools/`, which never runs in the app.

**Tech Stack:** HTML/CSS/JS (ES2022 modules), three.js r170 vendored to `vendor/three/`, Node 24 for tooling (`obj2gltf`, `@gltf-transform/cli`+`core`+`functions`, `meshoptimizer` as devDependencies only).

**Spec:** `docs/superpowers/specs/2026-11-25-anatomia-3d-design.md`

## Global Constraints

- No build step. The app loads only local files through relative paths (it has to work offline and later on GitHub Pages unchanged).
- No runtime CDN. three.js and fonts are vendored locally.
- Data: BodyParts3D (DBCLS), CC BY-SA 2.1 JP. Attribution appears in the app credits and in `docs/documentatie.md`.
- Colours: paper `#f4efe6`, ink `#1a1a1a`, one soft-red accent (builder picks the exact value and defines it once as `--accent`). The accent is used only for hover, correct and wrong states.
- Every GLB in `assets/models/` stays under about 5 MB.
- Every user-visible string goes through `t(key)` and lives in `data/strings.json` with both `ro` and `en`. Romanian is the default language.
- Code is readable, with few comments. No frameworks.
- Scoring: weights 100/66/33/0 for a correct answer on try 1/2/3/never. Time is shown, never added to the score. Best = higher %, and a tie goes to the shorter time.
- Progressive: unlock the next tier once the current tier reaches ≥80%.

## Review Focus

1. **Dragging to rotate must not count as a click.** If the pointer moves more than 5 px between down and up, no pick happens. (Task 5)
2. **Clicking empty space** (no mesh hit) is ignored: no try is used up. (Task 4, `answer(null)`)
3. **The target is on a hidden layer.** When the prompt names a part whose layer is off, that layer switches on automatically. (Task 7)
4. **localStorage is unavailable or throws** (private window, file blocked): the game still runs, and best scores and language just don't persist. (Task 3, `storage.js`)
5. **Typed answers vary in diacritics, case and spacing.** "Muschiul  biceps" matches "Mușchiul biceps". In Romanian, both ş/ș and ţ/ț (cedilla and comma forms) match. (Task 3, `normalize`)

### Task 4: Quiz logic (DOM-free)

**Files:**
- Create: `js/quiz.js`, `tests/quiz.test.mjs`

**Interfaces:**
- Consumes: the structure objects from Task 2.
- Produces:
  - `createQuiz({ structures, system, mode: "click"|"name", detail: "main"|"all"|"progressive", rng = Math.random }) → quiz`
  - `quiz.current → structure | null` (null when finished)
  - `quiz.answer(structureId: string | null) → { result: "ignored"|"correct"|"wrong"|"reveal", tries: number }`. `null` gives `ignored`. A wrong answer on the 3rd try gives `reveal` and moves on.
  - `quiz.skip()` counts as 0 and moves on.
  - `quiz.progress → { done, total }`, `quiz.score() → number 0–100 (rounded)`, `quiz.finished → bool`
  - `quiz.choices(n = 4) → structure[]` (for name mode: the current structure plus n-1 others from the same system, shuffled with `rng`)
  - `isBetter(a: {score, timeMs}, b: {score, timeMs} | null) → bool`
  - Pool: only the given `system`, never `skin`. `main` = tier 1. `all` = every tier. `progressive` starts with tier 1, and when the whole pool is done with score ≥80, the next tier's structures are appended.

- [ ] **Step 1: Write the failing tests.**
```js
const S = [ {id:'a',system:'bones',tier:1}, {id:'b',system:'bones',tier:1}, {id:'c',system:'bones',tier:2}, {id:'m',system:'muscles',tier:1} ];
const fixed = () => 0;
test('main uses tier 1 of system only', () => { const q = createQuiz({structures:S, system:'bones', mode:'click', detail:'main', rng:fixed}); assert.equal(q.progress.total, 2); });
test('null click ignored', () => { const q = createQuiz({structures:S, system:'bones', mode:'click', detail:'main', rng:fixed}); assert.equal(q.answer(null).result, 'ignored'); assert.equal(q.progress.done, 0); });
test('weights 100/66/33/0', () => {
  const q = createQuiz({structures:S, system:'bones', mode:'click', detail:'main', rng:fixed});
  q.answer(q.current.id);                         // 100
  const id = q.current.id; q.answer('zzz'); q.answer(id); // 66
  assert.equal(q.score(), 83); assert.ok(q.finished);
});
test('third miss reveals', () => { const q = createQuiz({structures:S, system:'bones', mode:'click', detail:'main', rng:fixed}); q.answer('x'); q.answer('x'); assert.equal(q.answer('x').result, 'reveal'); assert.equal(q.progress.done, 1); });
test('progressive unlocks tier 2 at >=80', () => { const q = createQuiz({structures:S, system:'bones', mode:'click', detail:'progressive', rng:fixed}); q.answer(q.current.id); q.answer(q.current.id); assert.ok(!q.finished); assert.equal(q.progress.total, 3); });
test('progressive stops below 80', () => { const q = createQuiz({structures:S, system:'bones', mode:'click', detail:'progressive', rng:fixed}); q.skip(); q.answer(q.current.id); assert.ok(q.finished); });
test('choices include current, same system', () => { const q = createQuiz({structures:S, system:'bones', mode:'name', detail:'all', rng:fixed}); const c = q.choices(3); assert.ok(c.includes(q.current)); assert.ok(c.every(s => s.system==='bones')); });
test('isBetter', () => { assert.ok(isBetter({score:90,timeMs:5}, null)); assert.ok(isBetter({score:90,timeMs:5},{score:90,timeMs:9})); assert.ok(!isBetter({score:80,timeMs:1},{score:90,timeMs:9})); });
```

### Task 5: 3D scene

**Files:**
- Create: `js/scene.js`

**Interfaces:**
- Consumes: the GLBs (Task 1), the structures (Task 2).
- Produces:
  - `createScene(canvas, structures) → Promise<scene>`. It loads all GLBs with GLTFLoader + MeshoptDecoder, applies one shared matte material per system (in ink/paper tones, skin translucent at about 0.15 opacity), and builds a `meshName → structureId` map.
  - `scene.setLayer(system, visible)`, `scene.layers → {skin, muscles, bones, nerves: bool}`
  - `scene.onPick(cb: (structureId | null) => void)`. It fires on pointerup only if the pointer moved ≤5 px since pointerdown, and only raycasts visible meshes (skin is never pickable).
  - `scene.onHover(cb: (structureId | null) => void)`
  - `scene.highlight(structureId, state: "hover"|"correct"|"wrong"|"target"|null)`. This is the outline (OutlinePass) plus an accent tint on the structure's meshes. It clears the previous highlight of the same state.
  - `scene.flyTo(structureId, ms = 800)` eases the camera and OrbitControls target to the bounding-box centre of the structure's meshes.
  - `scene.reset()` returns to the front view, `scene.dispose()`.
  - If WebGL isn't available: `createScene` rejects with `Error('webgl')`.

- [ ] **Step 1: Implement `js/scene.js`** to the interface. Use OrbitControls with damping and min/max distance clamped to the body bounds.
- [ ] **Step 2: Temporary browser check** with a scratch `?debug` path in `main.js` (removed in Task 7). Rotate and zoom both work. Hovering outlines a part. Dragging and releasing over a part doesn't log a pick. Clicking empty space logs `null`. `flyTo` glides smoothly. Toggling layers hides them. FPS is about 60 (DevTools performance overlay).
- [ ] **Step 3: Commit** with the message `feat: 3D scene, picking, outline, fly-to`.

### Task 6: Dithered title skeleton

**Files:**
- Create: `js/dither.js`

**Interfaces:**
- Consumes: `assets/models/bones.glb`.
- Produces: `createTitle(canvas) → { dispose() }`. It renders the slowly auto-rotating skeleton (about 0.15 rad/s) through an EffectComposer pass with a 4×4 or 8×8 Bayer ordered-dither ShaderPass that outputs only `--ink`/`--paper` (1-bit). The pixel size stays crisp at any devicePixelRatio (dither in screen-pixel blocks of about 2 CSS px).

- [ ] **Step 1: Implement `js/dither.js`.** The Bayer matrix is a uniform. Luminance is compared against the threshold, and ink or paper is output.
